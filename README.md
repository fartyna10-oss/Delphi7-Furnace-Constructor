# Delphi 7 3D Furnace Constructor

Интерактивный 3D симулятор и конструктор печей на Delphi 7 с использованием OpenGL.

## Возможности

- ✅ 3D визуализация компонентов печи
- ✅ Добавление и удаление элементов конструкции
- ✅ Редактирование параметров компонентов (размеры, позиция, поворот)
- ✅ Симуляция теплопередачи
- ✅ Сохранение и загрузка проектов
- ✅ Интерактивное управление камерой
- ✅ Отображение температурных параметров
- ✅ Совместимость с Delphi 7

## Структура проекта

```
.
├── FurnaceConstructor.dpr      - Главный файл проекта
├── MainForm.pas                - Главная форма приложения
├── FurnaceComponents.pas        - Определение компонентов печи
├── FurnaceEngine.pas            - Ядро симулятора
├── Rendering3D.pas              - 3D рендеринг (OpenGL)
├── MathUtils.pas                - Математические утилиты
└── README.md                    - Этот файл
```

## Компоненты печи

- **Chamber** - Основная камера печи
- **Wall** - Стены конструкции
- **Floor** - Пол печи
- **Door** - Дверца доступа
- **Vent** - Вентиляционное отверстие

## Требования

- Delphi 7 (Professional Edition или выше)
- OpenGL 1.2+
- Windows 95/98/ME/2000/XP/Vista/7

## Установка и запуск

1. Клонируйте репозиторий
2. Откройте `FurnaceConstructor.dpr` в IDE Delphi 7
3. Нажмите F9 или выберите Run → Run

## Использование

### Создание конструкции

1. Нажмите кнопку "Add Component" для добавления элемента
2. Выберите компонент из списка
3. Используйте панель свойств для настройки параметров
4. Нажмите "Apply" для применения изменений

### Симуляция

1. Установите параметры компонентов (температура, материал)
2. Нажмите кнопку "Simulate" для запуска симуляции
3. Наблюдайте изменение температурных параметров

### Сохранение проекта

- Нажмите "Save" для сохранения текущего проекта
- Нажмите "Load" для загрузки сохраненного проекта

## Архитектура

### FurnaceEngine
Основной модуль, отвечающий за:
- Управление компонентами
- Расчеты теплопередачи
- Сохранение/загрузку данных

### Rendering3D
Модуль визуализации:
- OpenGL рендеринг
- Управление камерой
- Отрисовка компонентов

### FurnaceComponents
Определение структур данных:
- TComponentType - типы компонентов
- TFurnaceComponent - базовый класс компонента

### MathUtils
Математические утилиты:
- Работа с трехмерными векторами
- Матричные преобразования
- Функции для поворотов и трансформаций
